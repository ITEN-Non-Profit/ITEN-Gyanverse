# IT CV and Resume Checklist

**Draft the CV → Review the checks below → Correct the draft before tailoring it**

Use these 20 checks to review the content, formatting, and final export of an entry-level IT CV. The contact details and results are examples. Use your own details and figures you can verify.

## A, Contact Information

### 1. Full Name
- **Do:** `Rajendra Kumar Shrestha`
- **Avoid:** `Raju` | `R.K. Shrestha` | `RAJENDRA SHRESTHA` | `Mr./Ms./Er. Rajendra`
- **Tip:** Use the name you apply under. Provide a legal name separately if the application requires it.

### 2. Phone Number
- **Do:** `+977 [mobile number]` (Nepal) | `+1-212-555-0100` (US example)
- **Avoid:** `[local number without country code]` | two numbers with no indication of which to use
- **Tip:** List one current number with the international country code. Check that it can receive calls.

### 3. Email Address
- **Do:** `rajendra.shrestha@example.com`
- **Avoid:** `coolboy123@example.com` | `[misspelled email]`
- **Check:** Use a professional address you check regularly, such as `firstname.lastname@example.com` in this example.
- **Review:** Check this inbox daily. Interview calls and offers are sent here.

### 4. Location
- **Do:** `Kathmandu, Bagmati Province, Nepal` (for Nepal jobs)
- **Do:** `Kathmandu, Nepal` (for international jobs)
- **Avoid:** `Ward No. 12, Baneshwor, Near Petrol Pump, Kathmandu 44600`
- **Tip:** City + Province + Country for Nepal. City + Country only for international.

### 5. LinkedIn URL
- **Do:** `https://www.linkedin.com/in/your-profile`
- **Avoid:** A broken, incomplete, or inaccessible profile link.
- **Check:** LinkedIn → Edit public profile & URL → type `firstname-lastname` → Save.
- **Tip:** Make it a clickable hyperlink in your CV.

### 6. GitHub / Portfolio
- **Do:** `github.com/your-username` | `portfolio.example.com`
- **Avoid:** Empty GitHub | Repos with no code | Broken link | `localhost:3000`
- **Review:** Every repo needs a README. Click and test every link. Empty GitHub = remove it.

## B, Content Sections

### 7. Career Objective, 2-3 sentences, no more
- **Do:** *"Final-year BIT student at TU skilled in Python and React, eager to contribute to a technology-driven team."*
- **Avoid:** *"I want to learn and grow my career."* | 6-line paragraph | Mentions salary or personal goals
- **Tip:** Formula: `[Degree + Institution]` + `[Top 2-3 skills]` + `[Value you bring]`. Never start with *'I am'*.

### 8. Education, Most Recent First
- **Do:** Bachelor of IT (BIT) | Tribhuvan University, Kathmandu | 2021-2025 | GPA: 3.6/4.0
- **Avoid:** SEE listed first | *'Tribhuban University'* | Year written as *'21-'25*
- **Tip:** Include the grade and grading scale when requested or useful. Verify the university name.

### 9. Skills, Two Groups: Technical and Soft
- **Do:** `Python, React, MySQL, Git, Docker` / `Problem-Solving, Communication, Teamwork`
- **Avoid:** Generic tool lists with no role relevance | `JavaScript 80%` | Self-assigned star ratings
- **Tip:** No ratings or bars. Only list skills you can confidently discuss in an interview.

### 10. Projects, Choose Your Strongest Evidence
- **Do:** *"Built an attendance system in PHP and MySQL, reducing record errors by 90% in the example test."* [Project URL]
- **Avoid:** *"Worked on a website."* | *"Did a project for college."* | GitHub link returns 404
- **Tip:** Formula per bullet: `[Verb]` + `[What]` + `[Tool]` + `[Result]`. GitHub link only if the repo has real content.

### 11. Work / Internship, If None, Expand Projects Instead
- **Do:** *"Developed three React components and reduced load time by 30% in a before-and-after test."* [Employer], June to August 2024
- **Avoid:** *"Was responsible for coding."* | *"I helped the team."* | Duties listed, not achievements
- **Tip:** Past-tense action verb first. No *'I'*. 2-4 bullets per role. No experience = remove section entirely.

### 12. Certifications | Extra-Curriculars | Achievements
- **Do:** Google IT Support Cert, Coursera, 2024
- **Do:** Secretary, IT Club TU, 2023-2024
- **Do:** Merit Scholarship, TU, 2022
- **Avoid:** *"Did a Python course"* | *"Was in a club"* | *"Got a scholarship"* | Incomplete courses listed
- **Tip:** Format all three as: `Name, Organization, Year`. Remove any section entirely if you have nothing to list.

### 13. Languages
- **Do:** Nepali, Native | English, Professional Working Proficiency | Hindi, Conversational
- **Avoid:** *"English, 80%"* | *"English, Very Good"* | *"English, Fluent"* if you are not fluent
- **Tip:** Use clear descriptions such as **Native / Fluent / Professional Working Proficiency / Conversational / Basic**

### 14. Photo & References
- **Do:** NO photo.
- **Do:** References: Do NOT write *'References available upon request'*, remove the line entirely.
- **Avoid:** Selfie or casual photo | Listing referees without their permission
- **Tip:** Follow the employer's instructions and local hiring conventions if a photo is requested.

## C, Formatting, Grammar & Export

### 15. Font, Size & Spacing
- **Do:** Font: Calibri, Arial, or Helvetica, one font throughout
- **Do:** Body text: 10.5-11 pt | Headings: 13-15 pt | Your name: 22-24 pt Bold | Line spacing: 1.15
- **Avoid:** 3 different fonts mixed | Body at 9 pt to squeeze content | Single line spacing (looks dense)
- **Tip:** Go to Paragraph settings → Line Spacing → set to 1.15. Apply to the entire document.

### 16. Layout & Length
- **Do:** Aim for one page as a new graduate. Use a second page for relevant material if needed. A simple single-column layout with readable margins is a good default.
- **Avoid:** 4-page fresher CV | Margins reduced to 0.3 inch | Tables/columns in ATS-targeted CV
- **Tip:** No star ratings, no decorative borders, no text boxes. Use a simple single-column version when submitting through a portal that parses CVs.

### 17. Bullets & Consistency
- **Do:** Same bullet symbol `•` throughout. Start each bullet with an action verb. Use present tense for ongoing work and past tense for completed work.
- **Avoid:** Mixed symbols (`•` `-` `▶`) across sections | *'Developed'* repeated 4 times in a row
- **Tip:** Vary verbs: Developed, Designed, Optimised, Deployed, Collaborated, Delivered, Resolved…

### 18. Grammar & Language
- **Do:** *"Developed a REST API using Node.js, reducing response time by 40%."*
- **Avoid:** *"I was responsible for developing..."* | *"We worked on..."* | Any spelling mistake anywhere
- **Check:** Use a spelling and grammar checker on a copy with private details removed. Read the CV aloud before submitting.
- **Tip:** No I / my / we. Past tense for past work. Short, direct sentences only. No vague adjectives.

### 19. Section Order Check
- **Do:** Name → Contact → Objective → Education → Skills → Projects → Experience → Certs → Extra-Curriculars → Languages
- **Avoid:** Random section order | Contact info buried in middle | Skills listed after Certifications
- **Tip:** Section order signals professionalism. Stick to the standard order above for general CVs.

### 20. Final File & Export
- **Do:** Follow the portal's file type and size requirements. For a DOCX, use `FirstName_LastName_CV.docx` e.g. `Rajendra_Shrestha_CV.docx`
- **Avoid:** `cv.docx` | `my resume final.docx` | `CVFINAL_v3_USE_THIS.docx` | File larger than the portal permits
- **Check:** Reopen the exported file. Test each link, check the pages on a phone, and make sure the text can be selected in the expected reading order. Clear any remaining draft placeholders.
- **Review:** Ask a trusted person, such as a mentor or experienced colleague, to review the final draft.

> **Do:** **All items checked → Export in the requested format → Tailor the CV to the role.**
