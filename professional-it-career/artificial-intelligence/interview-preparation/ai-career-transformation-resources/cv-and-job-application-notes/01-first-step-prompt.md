### Career Summary Instruction

Write a short professional summary based on my real background. Make it honest, confident, and suitable for a modern CV. Do not use generic lines like *"hardworking and passionate student"* unless supported by my projects, skills, or activities.

## CV Output Formatting Requirements

- Use a clean professional CV format.
- Use only **one professional font**: Calibri, Arial, or Helvetica.
- Body text: **10.5-11 pt** | Headings: **13-15 pt** | Line spacing: **1.15**
- Use consistent spacing and bullet formatting.
- Use **reverse chronological order** where dates are included.

## File Requirement

- Provide a downloadable DOCX if this chat supports file creation. Otherwise, return the CV as copyable text with the same section order so I can save it in Word.
- If you generate a DOCX, use `FirstName_LastName_CV.docx` as the filename.

## Important Context

This will be my **first master CV draft**, not a job-specific or ATS-tailored resume yet. Do not tailor it to one job description. Instead, create a clean, honest, professional CV based on my real background. Later, I will use this master CV to customize for specific jobs, internships, or scholarships.

## Important Rules

1. Use **only the information I provide**.
2. Do **not** add fake experience, fake certifications, fake company names, fake achievements, or fake technical skills.
3. Keep contact placeholders in the draft. Put other missing information in a separate follow-up list so it stays out of the CV.
4. If information is **weak**, improve the wording professionally, but do not exaggerate.
5. Start experience and project bullets with an action verb that reflects what I did. Label courses as training and earned credentials as certifications.
6. Use this bullet formula where possible:

   > **Action Verb** + Task/Project + Tool/Technology + Result, Output, or Learning

7. Keep the CV **ideally 1 page**. Use 2 pages only if the information is strong and necessary.

After generating the draft, complete the [CV checklist](02-cv-checklist.md) and replace the contact placeholders locally.
