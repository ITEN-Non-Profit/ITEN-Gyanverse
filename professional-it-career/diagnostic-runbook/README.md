### 📝 Short Description

The [**Field Handbook for Diagnostic Log Analysis**](https://github.com/ITEN-Non-Profit/ITEN-Gyanverse/blob/main/professional-it-career/diagnostic-runbook/markdown/Field_Handbook_for_Diagnostic_Log_Analysis.md) is an industry work-ready troubleshooting guide built to take practitioners from raw diagnostic evidence to a verified engineering action. It features **24 standardized AI-assisted prompt templates (`P01`–`P24`)**, strict data-safety rules to protect confidential logs, an **AI-Answer Quality Checklist**, and a **Quick-Use Matrix** across five core production domains:

| Domain | Prompt IDs | Core Day-to-Day Troubleshooting & Log Analysis Topics |
| :--- | :--- | :--- |
| 🖥️ **Part I: Incident & Windows** | `P01`, `P02`, `P12`, `P13` | Unified incident triage, Windows Event Log analysis, network path & SMB access triage, and OneDrive / Microsoft 365 sync issues |
| 🌐 **Part II: Network** | `P03`, `P05`, `P17`, `P18`, `P19`, `P21` | Connectivity & path analysis (`ping`, `traceroute`, `MTR`, `iPerf3`), packet loss, Spanning Tree (STP) Layer 2 instability, OSPF & BGP routing diagnosis, vendor CLI config validation, and PCAP packet capture analysis |
| 🛡️ **Part III: Security** | `P04`, `P06`, `P07`, `P08`, `P09`, `P10`, `P23` | Syslog security investigation, firewall policy review, EDR endpoint alert triage, MITRE ATT&CK detection coverage, CVE / CVSS / EPSS / KEV prioritization, living-off-the-land (LOLBIN) activity, and cloud identity audit trails (AWS CloudTrail, Entra ID, GCP) |
| ☁️ **Part IV: Platform & Resources** | `P20`, `P22`, `P24` | DNS diagnostics & PowerShell script design, Kubernetes (`kubectl`) workload failure diagnosis, and system memory / OOM / heap resource exhaustion |
| 📋 **Part V: Operations & RCA** | `P11`, `P14`, `P15`, `P16` | Repeated ticket pattern analysis, NOC/SOC shift handoff summaries, clear instructions for non-technical users, and network outage Root Cause Analysis (RCA) |
